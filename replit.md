# Awesome AI OSINT

A curated list of articles, videos, and tools related to the use of AI for OSINT (Open-Source Intelligence).

## Project Structure

- `README.md` — The main content file (Markdown list of resources)
- `server.py` — Simple Python HTTP server that renders README.md as a styled HTML page on port 5000

## Running

```
python server.py
```

Serves on `0.0.0.0:5000`.
